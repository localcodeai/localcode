# Session Notes - LocalCode

## What's Working

- TUI with chat interface
- Command confirmation dialog (Enter to run, N to cancel, edit before running)
- Uses real Apple Foundation Models (SystemLanguageModel.default) - on-device AI
- Pre-commit hook runs build + tests
- Go tests for runCommand, min, Message struct

## Test Commands That Work

- "list all python files" → find . -name "*.py"
- "show me the largest files" → find . -type f -exec ls -lS {} + | head -n 5
- "count all files in this directory" → find . -type f | wc -l
- "check if port 8080 is in use" → lsof -i :8080

## Known Limitations

- Model suggestions can be hit or miss (general-purpose model, not fine-tuned for CLI)
- Swift tests deferred (needs package.swift restructuring to run `swift test`)
- Exit code 1 (no matches found) is treated as valid result, not error

## Could Improve

- Refine AFM instructions for better command suggestions
- Add more Go tests for edge cases
- Add Swift tests (needs package.swift setup)
