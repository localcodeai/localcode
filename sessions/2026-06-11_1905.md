# Session: OpenCode Fork + AFM Provider Integration

**Date:** 2026-06-11
**Duration:** ~45 minutes

## What We Did

1. **Forked OpenCode**: `gh repo fork anomalyco/opencode`
   - Cloned to `/Users/christophercarvalho/localcode/opencode`

2. **Created AFM Provider Facade** in `packages/llm/src/providers/foundationmodels.ts`
   - Uses OpenAI Chat protocol (OpenAI-compatible route)
   - Points to `http://localhost:8080` by default
   - Auth: Bearer token "local" (placeholder)

3. **Created HTTP Server Wrapper** (`start-afm-server.sh`)
   - Bun script that wraps Swift AFM helper
   - Listens on port 8080
   - Converts HTTP POST requests to AFM CLI invocations

4. **Created LocalCode AFM Plugin** in `packages/core/src/plugin/provider/localcode-afm.ts`
   - Registers the foundationmodels provider
   - Sets default config for localhost:8080

5. **Registered Plugin** in `packages/core/src/plugin/provider.ts`
   - Added `LocalCodeAFMPlugin` to `ProviderPlugins` array

## Architecture

```
LocalCode (fork)
├── opencode/                           # Forked OpenCode
│   ├── packages/
│   │   ├── llm/src/providers/
│   │   │   └── foundationmodels.ts     # AFM Provider facade
│   │   └── core/src/plugin/provider/
│   │       ├── localcode-afm.ts        # AFM Plugin
│   │       └── provider.ts             # Updated with plugin
│   └── ...
├── LocalCode/                          # Original AFM helper
│   └── Sources/afmhelper/
│       └── main.swift                  # Swift AFM wrapper
└── start-afm-server.sh                 # HTTP server wrapper

User Flow:
1. Start AFM server: `./start-afm-server.sh`
2. Run OpenCode: `cd opencode && bun run dev`
3. Select "LocalCode AFM" provider in settings
4. Chat with the TUI → requests go to localhost:8080 → AFM helper → response
```
