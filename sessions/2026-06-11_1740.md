# Session: Migrate to OpenTUI

**Date:** 2026-06-11
**Duration:** ~30 minutes

## What We Did

Migrated LocalCode from Go/BubbleTea to TypeScript/OpenTUI.

### Migration Steps
1. Created new `tui/` directory with Bun + TypeScript
2. Installed `@opentui/core` and Zig via Homebrew
3. Built initial OpenTUI app with:
   - ScrollBox for messages
   - Input for user commands
   - AFM integration via Swift helper
   - Command execution via `/bin/sh -c`

### Key Fixes
- **AFM path**: Changed from absolute to `../../LocalCode/Sources/afmhelper/afmhelper`
- **AFM input**: Changed from stdin JSON to command-line argument
- **OpenTUI API**: Used `Text({})` construct API instead of `new TextRenderable()`
- **No clear()**: OpenTUI doesn't have clear - just add messages directly

### Pre-commit Hook
Updated `pre-commit.sh` to:
1. Build Swift AFM helper
2. Build TypeScript TUI with `bun run build`

Build command: `bun build src/index.ts --compile --outfile localcode`
